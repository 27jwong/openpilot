# Bolt Pedal configurations

The four `CHEVROLET_BOLT_*_PEDAL` and `CHEVROLET_BOLT_CC_*` configurations are separate from the existing stock-ACC Bolt EUV. The ordinary-cruise variants do not claim stock ACC; the ACC-pedal variant retains stock ACC cancellation but excludes simultaneous stock and pedal longitudinal control. Automatic platform identification is not provided: the available 2022–23 fingerprints overlap, and no distinguishing firmware set is available. A correctly identified configuration still needs a live 0x201 pedal sensor on bus 0 and an explicitly saved `GMPedalLongitudinal=true` setting. The fresh or unknown setting is off.

The controller uses the paired pedal tracks for acceleration, with a speed-shaped rate limit. It uses the regenerative paddle and PRNDL/ManualMode scheduler for braking. The source release packet has `PRNDL2=6`, which the DBC identifies as L. Until vehicle evidence supports another handoff, active pedal control and any paddle/gear spoof require a fresh stock L reading with ManualMode clear and no driver paddle input. Park, Reverse, Drive, and driver manual selection remain passive. This L-only rule is an intentional temporary coverage restriction relative to the frozen controller; merely producing a canonical packet does not prove a safe gear transition.

A healthy sensor, fresh stock source packets, active controls, no driver brake or pedal override, and (on the ACC variant) fresh confirmation that stock ACC is disengaged are also required for active commands. A fault, stale sensor, stock takeover, or control release sends an inactive pedal command; release paddle/gear feeds are sent only while actual L ownership remains qualified. Stock ACC cancel remains available on the ACC variant. Native safety validates pedal pairing, CRC, counter, source age, full scheduler payload shape, command bounds, and the same ownership exclusion. Each host scheduler feed is consumed by one matching stock packet; a fault, driver paddle, or gear change discards pending active feeds. It does not permit ASCM gas or friction-brake commands in these configurations.

The regenerative scheduler is required for this port. Gen2 friction braking, auto-hold, and one-pedal behavior remain disabled; no physical calibration or road validation is claimed. The 2017 calibration and later calibration come from the frozen implementation, but physical torque, brake handoff, standstill, near-stop behavior, and broader gear coverage still require vehicle evidence before release. The source byte and calibration provenance is maintained in the private migration audit. The test suite uses real generated DBC packing/parsing, controller output, and native C safety without vehicle communication.
